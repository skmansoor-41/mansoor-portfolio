# Education certificates

Add public certificates here as PDF files, using the filenames linked in the education popups:

- `pg-diploma.pdf`
- `banking-training.pdf`
- `btech-degree.pdf`
- `intermediate-memo.pdf`
- `ssc-memo.pdf`

Only upload documents you are comfortable making publicly accessible. Do not upload payslips, identity documents, or any confidential/private records to this public portfolio repository. A JavaScript password prompt on a static website is not secure access control. For private documents, use a private storage service with genuine access permissions or a server-side authenticated download.
